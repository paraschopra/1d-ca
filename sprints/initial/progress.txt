User Specification (verbatim)
-----------------------------
"I want to explore all 256 rules of 1d cellular automata. so make a self contained html page
with all of those starting with an on cell in the middle (but give me option an randomize
initial configuration). underneath each compute various metrics such as entropy etc."

Clarified Requirements
----------------------
- Single self-contained HTML file (all CSS/JS inline, no external dependencies)
- All 256 elementary cellular automata rules displayed in a responsive grid of cards
- Grid size: 128 columns x 128 generations per rule
- Boundary conditions: Wrap-around (periodic)
- Default initial config: Single center cell active
- Alternative: Random initial config with density slider (0-100%)
- Global "Randomize" button to regenerate all 256 with fresh random configs
- Click any card to expand into a detailed modal view

Metrics (Extended Set)
----------------------
- Shannon entropy
- Density (% alive cells)
- Mean field value
- Wolfram class (I-IV, heuristic)
- Symmetry score (left-right mirror)
- Lyapunov exponent estimate
- Compressibility ratio
- Period detection
